# Examify


**Тестовая оболочка для экзаменов**  

![Version](https://img.shields.io/badge/version-1.0.1.2b-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)

Версия: `1.0.1.2b` (14.05.2026)  
Формат тестов: `.exm` (редактирование через Examify Edit)  

Режимы: локальный / LAN / Файловая ассоциация

---

## Установка

1. Скачать архив из [Releases](https://github.com/Kefir234/Examify/releases)
2. Распаковать в любую папку
3. Настроить `config.cfg` (см. ниже)
4. Запустить `Examify.exe`

---

## Настройка `config.cfg`

Параметр `NetworkPath` — путь к папке `data` (содержит `userdata.cfg`, `tests/`, `certificate.png`).

|      Режим     |           Значение                  |
|----------------|-------------------------------------|
| Сетевой (UNC)  | `NetworkPath=\\SERVER\Examify\data` |
| Локальный диск | `NetworkPath=D:\Examify\data`       |

---

## Сетевой режим (учитель + ученики)

**Условия:** все ПК в одной LAN, общая папка с правами чтения/записи.

|   Роль  |                                            Файлы                                             |
|---------|----------------------------------------------------------------------------------------------|
| Учитель | `Examify.exe`, `ExamifyEdit.exe`, `license.dat`, `data/` (полная)                            |
| Ученик  | `Examify.exe`, `config.cfg`, `license.dat` (в `config.cfg` указан UNC-путь к `data` учителя) |

---

## Структура файлов

```
Examify/
├── Examify.exe          # Клиент тестирования
├── ExamifyEdit.exe      # Редактор тестов
├── config.cfg           # Путь к data
├── license.dat          # Лицензия
├── data/
│   ├── tests/           # *.exm — файлы тестов
│   ├── userdata.cfg     # Результаты пользователей
│   └── certificate.png  # Шаблон сертификата
```

## Ассоциация `.exm`

Автоматическая при первом запуске `Examify.exe`.  
При необходимости — назначить вручную: **Открыть с помощью** → `Examify.exe` → ✅ «Всегда использовать».

## Безопасность

Все файлы тестов и пользовательских данных, хранящиеся на главном компьютере, защищены с использованием алгоритма симметричного шифрования **AES-256**.

Расшифровка данных производится **исключительно на стороне клиента** (рабочей станции). Ключи шифрования не передаются по сети и не хранятся на сервере.

Данный подход обеспечивает:
- Конфиденциальность данных при передаче по локальной сети
- Защиту от перехвата и тамперинга (несанкционированной модификации данных)
- Отсутствие возможности расшифровки данных третьими лицами без доступа к клиентскому приложению
